# 달토끼 (DalTokki)

**졸음이 올 때 먼저 말을 걸어주는 AI 동승 친구**

차량 데이터(속도·기어 + Pleos Vehicle SDK의 핸들 각도·방향지시등·브레이크·경고등·공조 상태)로 운전자의 피로 징후를 추정하고, 피로가 의심되면 AI 캐릭터 '달토끼'가 먼저 말을 겁니다. **말을 걸지 않아도 '핸들 무조작 후 급꺾음' 패턴으로 먼저 알아채고**, 대화와 끝말잇기·퀴즈로 깨어 있는지 확인하며, 그 대화의 응답 속도와 무응답 여부를 다시 피로 판정에 반영합니다. 차선 변경·제동 중에는 말을 걸지 않고, 왜 그렇게 판단했는지 근거를 화면에 보여줍니다. 차량이 운전자 주의 경고를 띄우면 바로 휴식을 권하고, 위험 단계에서는 공공데이터 휴게소 중 **같은 방향 차로**의 가까운 곳을 안내해 Pleos NaviHelper로 경로에 추가합니다. Gleo 음성비서에서도 "달토끼랑 끝말잇기", "졸려", "휴게소 들르자"로 부를 수 있습니다.

- 패키지명: `app.daltokki.drive`
- 플랫폼: Pleos Connect (Android Automotive OS 기반). 테스트용으로 휴대폰에도 설치 가능(시뮬레이션 모드)
- 사용 Pleos SDK: Vehicle 2.3.2, NaviHelper 3.0.5, TextToSpeech 3.3.1, SpeechToText 3.3.1(온디바이스), Gleo Interface(App Schema)

## 실행 방법

1. Android Studio에서 이 폴더를 엽니다. (SDK Manager에서 **Android 15.0 (API 35) SDK Platform** 설치 필요 — compileSdk 35)
2. Pleos Connect 에뮬레이터(AVD) 또는 **휴대폰**을 연결합니다.
3. `app`을 실행합니다. (또는 `apk/` 폴더의 APK를 `adb install`로 설치)
   - **차량(에뮬레이터)**: 앱을 열면 바로 실차 모드로 감시를 시작합니다.
   - **휴대폰**: 자동으로 시뮬레이션 모드. 세로 화면은 위가 앱 화면, 아래가 데모 패널입니다.
4. **앱을 켜면 일상 화면**(시연 버튼 없는 정차 화면)이 먼저 나옵니다. **시연은 왼쪽 위 작은 "데모 ☰" 버튼 → 데모 패널**에서 시작합니다(새벽 고속도로 · 졸음 발생 · 시뮬레이션 · 30배속 · 말 수 `수다`).
   - **▶ 자동 시연 · 새벽 졸음** (녹화용, 패널 맨 위): 누르면 패널이 닫히고 카운트다운 후 시작. 운전자 대답을 대본대로 앱이 자동으로 넣습니다. → 아래 [자동 시연](#자동-시연-녹화용)
   - **수동 시연** (PT 현장): 새벽 졸음 / 오전 정상(오탐 없음) / 2시간 연속. 운전자가 마이크나 패널의 추천 대답 버튼으로 직접 대답합니다.
   - 시연용 설정은 저장하지 않으므로 앱을 다시 열면 원래 설정(실차 모드 등)으로 돌아갑니다.
   - 달토끼가 말을 걸면 자동으로 1배속이 됩니다. 마이크가 없으면 데모 패널의 추천 대답 버튼(응, 아니, 끝말잇기 단어…)이나 입력창으로 대답합니다.
   - 명령줄(PowerShell): `& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" -e shell am start -n app.daltokki.drive/.ui.MainActivity --es demo night` (`night` / `day` / `long`, 휴대폰은 `-d`). 자동 시연은 뒤에 `--ez auto true`
5. **오늘 컨디션**: 정차 화면에서 어젯밤 잔 시간을 누르면(말 수 '수다'는 출발할 때 달토끼가 음성으로 물음) 오늘의 권장 휴식 간격이 정해집니다. 시연 시작은 매번 이 질문부터 합니다.
6. 화면 크기: 1280×720dp보다 큰 창에서는 화면 전체를 1~2배로 키웁니다(에뮬레이터 2560×1440 · 160dpi → 약 1.8배). 16:9보다 세로가 긴 창(Pleos Connect 에뮬레이터 가운데 화면 등)은 기준 폭을 1120dp로 잡아 조금 더 키웁니다. 넓은 창에서 주행 화면은 2단, 정차 화면은 3단으로 배치됩니다.
   - **정차 화면(일상 화면)**: 화면 세로 가운데에 세 칸 높이를 맞춰 배치. ① 달토끼 · [👤 운전자 이름  변경 ▾] · [달토끼야] [말놀이 게임] ② 오늘 컨디션(어젯밤 잠 → "오늘은 75분마다 쉬어가요") ③ 나의 기록(달 레벨 · 도장 · 배지 · 지난 운행). 늘 떠 있는 안내 문구는 없고, 달토끼가 방금 한 말만 버튼 아래 2줄 자리에 20초 보입니다(자리는 늘 비워 두어 버튼이 움직이지 않음). 주행 화면 버튼은 오른쪽 칸 맨 아래에 고정입니다. 휴식 중이면 ①은 꾸벅 달토끼·"7분 더 쉬어요"·[커피냅 15분] [운행 종료], ②는 스트레칭.
   - 처음 실행(운전자가 기본 이름 '운전자 1' 한 명뿐)이면 운전자 고르기 창이 한 번 저절로 열립니다.
   - **디자인 A안 "달빛 미니멀"**(18차): 짙은 남색 + 달빛 노랑. **글자 크기 기준**(1280×720 기준): 운전 중 상태 104sp, 위험도 48sp, 달토끼 말 36sp, 근거 26sp, 버튼 120dp/34sp(마이크는 버튼 줄 맨 앞), 정차 화면 본문 24sp 이상·큰 숫자 104sp, 가장 작은 글자 17sp.

### 자동 시연 (녹화용)

소리·마이크가 안 되는 PC에서도 한 번에 녹화할 수 있게, 운전자 대답을 대본대로 자동으로 넣습니다. **졸음 판정과 대화 흐름은 실제 엔진 그대로**이고, 자동 운전자는 대답과 대답 속도만 대신합니다(또렷할 때 빠르게 → 피곤하면 느리게 → 졸음 구간에서는 대답 안 함). 그래서 화면의 근거("대답이 평소의 2배", "무응답")는 엔진이 실제로 계산한 값입니다.

| 장면 | 화면 | 자동 운전자 |
|---|---|---|
| ① 운전자별 습관 기억 | 시연 운전자 "운전자 1"(지난 12회 습관·도장 4곳·1,300점) → 출발하자마자 판단 | |
| 기억하는 대화 | "좋아, 출발하자! 오늘도 부산 가?" (기본 이름이라 이름은 부르지 않음) | "응, 부산 가" |
| ② 출발 전 컨디션 | "어젯밤 몇 시간 잤어?" → 권장 휴식 75분 | "다섯 시간 잤어" |
| (학습 끝나면) 졸린 날은 습관을 배우지 않아요 | 새벽 운행이라 오늘 습관은 누적에서 뺌 | |
| ② 멀쩡할 때는 조용히 | 차선 변경 5초 → "차선 변경 중 · 달토끼는 잠깐 기다려요" | (방향지시등 자동) |
| ③ 말 걸기 전에 먼저 알아채요 | 피로 누적 · 핸들 급꺾음 근거 | 말 걸기에 느리게 대답 |
| ④ 통화 중에는 기다려요 | 통화 12초 → "통화 중 · 달토끼는 기다려요" | (통화 자동) |
| ⑤ 게임으로 깨어 있게 | 초성 게임 3문제 정답 · '초성 박사' 배지 | "달토끼야, 초성 게임 하자" → 정답 3개 |
| 실내 공기도 봐요 | 내기순환 CO₂ 추정 → "바깥 공기로 바꿔 줄까?" → Pleos 공조 외기 전환 | "응, 바꿔 줘" |
| ⑥ 졸음 신호가 쌓이면 | 경고 · 반응 게임 제안 | "반응 게임 하자"(느리게) |
| ⑦ 반응 게임 | "달!" → "빛!" 1.3초 · 1.9초 · 놓침 → 휴게소 권유 | 권유에는 대답 안 함(무응답) |
| ⑧ 위험 · 차량 주의 경고 | 위험 → 망향휴게소 카드 "좋아하는 국밥도 있대" | "응, 경로에 추가해줘" |
| ⑨ 쉬는 게 가장 큰 보상 | 휴게소 도착 | |
| 커피냅 15분 | "15분만 눈 붙여 볼래?" → 깨우고 반응 재측정(1.6초 → 0.7초) · '개운한 커피냅' → 도장 쾅(경부선 5곳째) · '노선 탐방'·'새벽 지킴이' 배지 · 볼록달 | "응, 잠깐 잘게" → "빛!" 3번 |
| ⑩ 운행 리포트 | 리포트 → 종료 카드 | |

(순서는 상황에 따라 조금 바뀔 수 있고, 번호는 화면에 나온 순서대로 붙습니다. 시연 운전자 "운전자 1"은 임시 운전자라 실제 운전자 기록은 바뀌지 않고, 종료 카드를 닫으면 원래 운전자로 돌아갑니다.)

- **화면**: 시작 전 3·2·1 카운트다운, 맨 위 줄에 장면 자막(①…)과 "자동 시연 · 운전자 응답 자동" 표시(■ 중지), 운전자 대답은 달토끼 말 카드 안에 파란 말풍선, 끝나면 종료 카드. 데모 패널은 숨겨집니다.
- **대사 고정**: 자동 시연은 매번 같은 대사를 고릅니다(무작위 고정). 미리 만든 음성을 다시 녹화해도 쓸 수 있습니다. 시점은 몇 초씩 다를 수 있으니 큐시트 기준으로 맞춥니다.
- **문장 표시 시간**: 소리가 안 나도 읽을 수 있게 한 문장을 최소 0.5초 + 글자당 0.115초 보여줍니다(나중에 음성을 입힐 자리).
- **운전자 목소리**: 안드로이드 기본 TTS의 한국어 남성 음성(없으면 음높이를 낮춤). 한국어 음성이 없거나 소리가 안 나는 PC면 말풍선만 나옵니다.
- **대사 큐시트**: 끝나면(10초마다 중간 저장) 아래 폴더에 저장됩니다. 시각 0 = 자동 시연 버튼을 누른 순간(카운트다운 "3"이 뜬 화면).
  ```
  adb pull /sdcard/Android/data/app.daltokki.drive/files/demo/ .
  ```
  - `latest_dialog.srt`: "달토끼: …", "운전자: …" 자막 (편집기에 자막으로 넣거나 음성을 입힐 위치)
  - `latest_captions.srt`: 장면 자막
  - `latest_cue.tsv`: 시작초·끝초·화자·문장 (엑셀에서 열어 TTS 대본으로)
  - 같은 내용이 `날짜_시각_…` 이름으로도 남습니다.
- **Pleos 내비**: 시뮬레이션이어도 차량(에뮬레이터)이면 경유지 추가 때 Pleos NaviHelper를 실제로 한 번 호출하고 결과를 기록에 남깁니다(안내 중인 경로가 없으면 실패로 기록되고 시연은 그대로 진행).

### 빌드 설정 (gradle.properties)

| 설정 | 기본 | 설명 |
|---|---|---|
| `pleosSdk` | `true` | Pleos Vehicle·NaviHelper·TextToSpeech·SpeechToText SDK 포함(`app/src/pleos`). Pleos 저장소 접속 문제 등으로 빌드가 막히면 `false` → SDK 없이 빌드(`app/src/nopleos`) |
| `carOnly` | `false` | `false`면 휴대폰에도 설치 가능. App Market에 차량 전용으로 낼 때만 `true` |

### 명령줄 빌드

```bash
# Windows (명령 프롬프트 / PowerShell)
gradlew.bat assembleDebug          # 디버그 APK
gradlew.bat assembleRelease        # 출시 APK (keystore.properties가 없으면 디버그 키로 서명)
gradlew.bat testDebugUnitTest      # 단위 테스트

# macOS / Linux
./gradlew assembleDebug
```

### Windows 노트북에서 처음 열 때

- Gradle 동기화 중 `Failed to find target android-34`가 나오면 SDK Manager → SDK Platforms에서 **Android 14.0 (API 34) SDK Platform**을 설치합니다. (Pleos 시스템 이미지와 별개)
- Gradle JDK는 Android Studio 내장 JDK(JBR 17 또는 21)를 그대로 쓰면 됩니다.
- `local.properties`는 Android Studio가 자동으로 만듭니다.

### 에뮬레이터에서 대답하는 방법

- **음성:** 에뮬레이터 **⋯ (Extended Controls) > Microphone**에서 PC 마이크 입력을 켭니다. Windows 설정 > 개인 정보 > 마이크에서 데스크톱 앱 허용도 필요합니다.
- **버튼:** 에뮬레이터에서는 한글 키보드 입력이 불편하므로, 달토끼가 대답을 기다리는 동안 데모 패널 맨 위에 **추천 대답 버튼**이 나옵니다. (끝말잇기는 규칙에 맞는 단어, 퀴즈는 정답/모르겠어, 질문에는 응/아니 등)
- **입력창:** 데모 패널 아래 입력창에 직접 써도 됩니다.

출시 키로 서명하려면 프로젝트 루트에 `keystore.properties`를 만듭니다.

```properties
storeFile=../keys/release.jks
storePassword=****
keyAlias=****
keyPassword=****
```

## 동작 방식

### 1. 피로 추정 (세 가지 신호 + 차량 경고)

| 신호 | 출처 | 내용 |
|---|---|---|
| 상황 위험도 | 기어·속도·시각 (Car API) | 연속 운전 시간(60분부터 상승), 시간대(새벽 2~5시, 오후 2~4시), 고속 단조 주행 |
| 핸들 조작 이상 | 핸들 각도 (Vehicle SDK SteeringWheel) | 핸들 반전 빈도 감소, **핸들 무조작 후 급꺾음**(3초 이상 ±0.3° 안에서 거의 안 움직이다가 1초 안에 초당 12° 이상 빠르게 꺾음, 최근 5분 횟수 — 가장 강한 졸음 신호), 속도 편차 증가 |
| 대화 반응 저하 | 달토끼와의 대화 | 질문 후 응답 지연, 무응답 (짧은 질문과 게임은 기준을 따로) |
| (보조) 차선 이탈 | 경고등 ELK·LKA 깜빡임 (Vehicle SDK Safety) | 최근 5분 차로 유지 개입 횟수 |
| 차량 운전자 주의 경고 | 경고등 DRIVER_ATTENTION (Vehicle SDK Safety) | 켜지면 5분간 '위험' |

- 핸들 지표는 **고속(60km/h 이상) 직진 구간**에서만 계산하고, 차로 유지 보조(LKA/LFA 경고등)가 켜져 있거나 **방향지시등을 켠 차선 변경**(꺼진 뒤 3초 포함)은 제외합니다.
- 운전 시작 후 15분(유효 주행 기준)의 핸들 습관(미세 보정 빈도·속도 흔들림)을 **개인 기준선**으로 만들고, 이후에는 기준선 대비 변화로 판단합니다.
- 응답 속도 기준은 또렷할 때('좋아요' 단계) 받은 짧은 대답으로 정합니다. 게임 대답은 단어를 떠올리는 시간이 있어 4초 기준으로 따로 봅니다.

### 운전자별 누적 습관 (차 한 대를 여러 명이)

- **운전자 추가·선택**: 정차 화면 첫 칸의 **[👤 운전자 1  변경 ▾]** 버튼 → 맨 위 **이름 칸**에서 지금 운전자 이름 바로 바꾸기, 목록에서 고르기, **+ 운전자 추가**(이름 칸에 "운전자 2"처럼 기본 이름이 미리 채워져 [추가]만 누르면 됨. 아빠·엄마… 빠른 이름은 아래 보조 버튼, 최대 6명), **게스트**(판단은 기본값, 습관·도장 기록 안 함). 마지막 운전자가 기본값이라 매번 고를 필요는 없습니다. 운행 중(휴식 포함)에는 바꾸지 않습니다.
- **운전자별로 따로 기억**: 운전 습관, 평소 대답 속도, 말 수, 어젯밤 잠, 휴게소 도장, 달 레벨(누적 점수), 배지, 지난 운행 리포트. 달토끼가 인사할 때 이름을 부릅니다("엄마, 좋아 출발하자!"). 기본 이름("운전자 N")이면 이름을 부르지 않습니다("운전자 일, …"이 어색해서).
- **습관 누적**: 운행마다 배운 습관을 속도대별(시속 60~90km / 90km 이상)로 최근 20회까지 보관하고 **중앙값**을 씁니다. **3회 이상 쌓이면 출발하자마자 판단**(15분 '익히는 중' 없음, 주행 화면에 "운전자 1의 습관 12회 기억 · 바로 판단해요"). 그날 습관이 완성되면 누적 70% + 오늘 30%로 섞어 컨디션을 반영합니다.
- **졸린 날은 배우지 않음**: 배우는 동안 '좋아요'가 아니었거나 핸들 무조작 후 급꺾음이 있었던 운행, 새벽(0~5시) 운행, 수면 6시간 미만이라고 답한 날의 습관은 누적하지 않습니다(그냥 쌓으면 기준이 점점 무뎌짐). 대답 속도 기준도 같은 조건에서만 쌓습니다.
- **다른 사람이 운전했을 때**: 오늘 습관이 누적 습관의 50% 미만·200% 초과면 학습에서 빼고, 정차 화면에 "혹시 다른 분이 운전하셨어요?" 카드 → [아빠 맞아요] / [다른 운전자](고른 사람 습관으로) / [이번 운행은 학습 안 함].
- **관리**: 목록의 "관리"에서 이름 바꾸기, **운전 습관 다시 배우기**, 삭제(마지막 한 명은 삭제 불가). 습관은 이 기기에만 저장됩니다.
- 이전 버전 기록(말 수·잠·점수·배지·도장)은 처음 실행할 때 **"운전자 1"**로 옮겨집니다.
- 점수 = 상황 × 0.25 + 행동 신호(핸들 0.45, 차선 0.10, 대화 0.20).
  - 핸들 신호가 있으면 없는 행동 신호의 가중치를 있는 신호에 나눠 줍니다.
  - 핸들 신호가 없으면(저속·커브·데이터 없음) 대화·차선은 각자 가중치 × 1.5까지만, 합계 최대 0.35 (무응답 한 번으로 '위험'이 되지 않게).
- 단계: 좋아요 < 0.30 ≤ 주의 < 0.50 ≤ 경고 < 0.75 ≤ 위험
- 규칙: 연속 운전 2시간 이상이면 최소 "주의", 운전자가 "졸려"라고 하면 최소 "경고", 차량 운전자 주의 경고면 "위험". 10분 이상 쉬면 피로 누적을 초기화합니다.

모든 기준값은 `domain/fatigue/FatigueConfig.kt` 한 곳에 있습니다.

### 2. 게임 규칙 — 깨어 있음 확인

**화면의 게이지 = 실제 졸음 위험도**(핸들·연속 운전·시간대·대화 반응). 게임을 해도 숫자는 내려가지 않습니다.
게임·빠른 대답은 **"깨어 있음 확인 +N"** 으로 따로 쌓이고, 달토끼가 **말을 덜 거는 데만** 씁니다(말 걸기 판단 = 위험도 − 깨어 있음 확인).
근거: 피로할 때 맞춰 준 짧은 말하기 과제가 각성도와 주행 성능을 일시적으로 높였다는 연구(Atchley 외 2014, Human Factors) — 그래서 경고 단계에서만 게임을 제안하고, 효과는 10분이면 사라지게 했습니다.

| 규칙 | 내용 |
|---|---|
| 확인은 실력으로만 | 끝말잇기·퀴즈 정답(4초 안이면 4점, 아니면 2.5점), 달토끼 질문에 빠른 대답(2점). 사전에 없는 단어는 빠른 정답 보너스 없음 |
| "안 졸려"는 말로만 안 됨 | 먼저 한 말은 0점. 달토끼 질문에 빠르게 답했을 때만 1점. 대신 "끝말잇기로 증명해 볼래?"로 게임을 제안 |
| 상한 | 최대 15점, 10분이면 사라짐 (계속 놀아야 유지) |
| 안전 한도 | 위험(75) 이상이면 무효·게임 멈춤 / 급꺾음 반복·2시간 연속·차량 주의 경고면 '경고'(50) 아래로 말 걸기 판단을 못 내림 / "졸려"라고 했으면 '경고' 유지 |
| 진짜 초기화는 휴식 | 10분 쉬면 위험도 0, **+500점**(가장 큰 점수)과 '휴식 지킴이' 배지 |

각성 점수: 정답 50점(반응 게임 30점) × **콤보 배율**(2연속 ×1.5, 3연속 ×2, 5연속부터 ×3) + 빠른 정답(번개) 30점, 휴식 +500점, 처음 가 본 휴게소 도장 +200점, 커피냅 뒤 반응이 빨라지면 +100점. 배지 17종(첫 끝말잇기, 5연속 정답, 번개 반응, 휴식 지킴이, 새벽 지킴이 1,500점, 안전 드라이버 5,000점, 첫 도장, 도장 수집가 10곳, 쉼터 탐험가 졸음쉼터 3곳, 노선 탐방 한 노선 5곳, 초성 박사, 휴게소 미식가, 기억력 대장, 수수께끼 왕, 개운한 커피냅, 상쾌한 운전, 제때 쉬기). 누적 점수·배지·도장은 기기에 저장됩니다.

#### 게임이 곧 측정 — 피로에 맞춘 난이도
| 피로 단계 | 게임 |
|---|---|
| 좋아요·주의 | 끝말잇기 6턴, 퀴즈 3문제, 반응 게임 5번 |
| 경고 | **반응 게임을 먼저 권함**(3번). 끝말잇기는 3턴, 퀴즈는 2문제로 짧게. 끝말잇기 도중 경고로 오르면 "더 간단한 반응 게임으로 바꿀게" |
| 위험 | 게임 멈춤 → 휴게소 안내 |

- **반응 게임("달!" → "빛!")**: 1.5~4초 무작위로 기다렸다가 "띵 + 달!" → 운전자가 바로 "빛!". 졸음 연구의 반응 시간 검사(PVT)를 음성으로 바꾼 것으로, 생각할 게 거의 없어 피곤할 때도 부담이 적고 **반응 시간 자체가 졸음 판정 근거**가 됩니다(기준 1.2초, 놓치면 무응답에 가까운 신호). 두 번 놓치거나 평균이 1.8초보다 느리면 휴게소를 권합니다.
- 주행·정차 화면의 게임 버튼(평소 [말놀이 게임], 경고 [짧은 게임])을 누르면 **게임 고르기 창**(큰 칸 2줄×4칸): 첫 칸 **[알아서 골라 줘]**(피로 단계에 맞게 돌아가며) + 게임 7가지. '경고'에서는 반응 게임·숫자 따라 말하기만 누를 수 있고 나머지는 흐리게 "지금은 짧은 게임만". 말로 "초성 게임 하자"도 그대로 됩니다.
- **게임 중에는 그 버튼이 [게임 그만]**: 누르면 바로 멈추고 "알겠어, 여기까지!"("그만할래"라고 말한 것과 같음).
- 위험 단계 휴게소 카드: "10분 쉬면 위험도 0 · +500점"(10분 쉬면 받는 각성 점수)

#### 게임 7가지 (14차, 거꾸로 세기처럼 생각 부담이 큰 게임은 넣지 않음)
| 게임 | 예 | 피로 단계 | 배지 |
|---|---|---|---|
| 끝말잇기 | "기차" → "차표" | 좋아요·주의 | 첫 끝말잇기 |
| 초성 게임 | "기역 치읓!" → "기차" | 좋아요·주의 | 초성 박사(한 운행 3번) |
| 상식 퀴즈 | "대한민국의 수도는?" | 좋아요·주의 | |
| 휴게소 음식 퀴즈 | "망향휴게소 대표 메뉴는?" (공공데이터 대표 음식, 같은 노선 먼저) | 좋아요·주의 | 휴게소 미식가 |
| 수수께끼 | "다리는 넷인데 걷지 못하는 것은?" | 좋아요·주의 | 수수께끼 왕(한 운행 2번) |
| 숫자 따라 말하기 | "3, 7, 1, 9" → "삼 칠 일 구"(셋·여덟 같은 고유어도 인식) | 경고에서도 | 기억력 대장(네 자리) |
| 반응 게임 | "달!" → "빛!" | 경고에서도 | 번개 반응 |
- 좋아요·주의는 말놀이 5가지를 돌아가며(최근 2번 한 것은 피함), 경고는 반응·숫자 게임만, 위험은 게임 대신 휴식.
- **지루함 예방 말놀이**: 고속도로(시속 80km 이상) 60분 넘게 연속이고 아직 '좋아요·주의'면 졸리기 전에 "한 판 할래?" (보통·수다, 30분 간격, 시간당 상한 포함)

#### 커피냅 15분
- 휴게소 도착 → "커피 한 잔 마시고 15분만 눈 붙여 볼래?" (또는 정차 화면 [커피냅 15분]) → 15분 뒤 깨우는 소리 → 반응 게임 3번으로 다시 재서 "1.6초에서 0.7초로 빨라졌어!" → 빨라졌으면 +100점·'개운한 커피냅' 배지. 자는 동안의 도장·휴식 완료 안내는 깬 뒤로 미룹니다.

#### 실내 공기(CO₂) 추정 → 외기 전환
- 내기순환·풍량·탑승 인원으로 공기 수지 식(dC/dt = N·G/V − λ(C − 420ppm))을 풀어 실내 CO₂를 추정합니다(`domain/fatigue/CabinAirModel.kt`). 혼자 내기순환이면 약 8분에 1,200ppm.
- 보조 지표: 졸음 위험도(상황)에 최대 +0.1, 1,500ppm 이상이면 근거 알약 표시.
- 1,200ppm(또는 내기순환 20분) + '주의'면 "바깥 공기로 바꿔 줄까?" → "응" → Pleos 공조 외기 전환. 안 되면 음성으로 안내. 운전자가 승낙한 뒤에만 바꿉니다.

#### 기억하는 대화
- 운전자 말에서 자주 가는 곳·좋아하는 음식·음료·음악만 뽑아 운전자별로 기기 안에 저장 → "오늘도 부산 가?", 휴게소 권유·도장 안내에 "좋아하는 국밥도 있대". 운전자 관리 창에서 확인·[기억 지우기].

#### 휴게소 도장 깨기
- 실제 휴게소·졸음쉼터(공공데이터 **447곳**)에서 10분 쉬면 그곳 **도장**을 받습니다. 게임의 목표가 "쉬기"라서 재미와 안전이 같은 방향입니다(오래 운전할수록 이득이 되지 않음).
- 실차: 휴식을 시작할 때 현재 위치 700m 안의 휴게소·쉼터를 찾습니다. 시연: 시나리오의 실제 휴게소(새벽 졸음 = 경부선 **망향휴게소**, 2시간 연속 = 칠곡휴게소)
- 달토끼: 보통 "망향휴게소 도장 쾅! 3곳째 도장이야." / 수다는 공공데이터의 **대표 음식**까지("여기 대표 메뉴는 명품한우국밥래.") / 최소는 효과음만
- 정차 화면 "나의 기록" 카드: 도장 수(전국 447곳 중), 달 레벨, 배지 수, 지난 운행. 새 배지를 받으면 맨 위에 크게

|---|---|---|
| 모름 | 120분 | 90분 |
| 6시간 이상 | 120분 | 90분 |
| 5~6시간 | 90분 | 90분 |
| 4~5시간 | 75분 | 75분 |

- 권장 간격이 지나면 '주의' 하한이 걸려 달토끼가 휴식을 권하고, 근거에 "권장 휴식 간격 75분 지남", "수면 4시간"이 나옵니다. 수면 부족은 상황 위험도에도 더합니다(최대 +0.25).

#### 소리·음성 인식 배려
- 달토끼가 말하는 동안 음악·라디오 소리를 줄였다가(오디오 포커스 덕킹) 끝나면 되돌립니다.
- **통화 중에는 먼저 말을 걸지 않습니다**(위험 경고 포함, 화면 표시는 그대로). 대화 중에 통화가 시작되면 달토끼가 말을 멈춥니다. 데모 패널 "통화 중 15초"로 시험.
- **음성 인식이 듣지 못하는 상태**(인식기 없음·곧바로 계속 실패)의 '대답 없음'은 무응답(졸음 신호)으로 세지 않습니다. 반응 게임도 그 판은 측정에서 빼고, 두 번 연속이면 게임을 멈춥니다.

#### 검증 리포트
- `gradlew.bat testDebugUnitTest --tests "*ValidationReportTest*"` → `app\build\reports\luna-validation\validation_report.md`
- 시나리오를 운전자 습관(핸들 진폭·주기·속도)과 난수를 바꿔 20회씩 돌려 정상 주행 오탐률, 졸음 감지율, **차량 주의 경고(DAW)보다 먼저 감지한 비율·시간**, 장거리 휴식 권유 시점(수면별), 반응 게임 판정(가정 분포)을 표로 만듭니다.

#### 효과음
- 게임 시작·정답(콤보가 이어질수록 음이 올라감)·오답(부드럽게)·반응 신호·배지·도장·휴식 완료. 소리 파일 없이 코드로 합성(`voice/SoundEffects.kt`)하고 달토끼 목소리와 같은 음성 비서 오디오로 냅니다.
- 운전 중에는 화면 연출 대신 소리로 게임 느낌을 주고, 점수판·배지·도장 카드는 정차 화면에서만 보여줍니다.

### 3. 달토끼의 개입 — 말 수 설정 (기본: 최소)

원칙은 **화면이 먼저, 소리는 마지막**입니다.

| 상황 | 최소 (기본) | 보통 | 수다 |
|---|---|---|---|
| 출발 | 말 없음 | 인사 한 문장 | 인사 + 질문 |
| 주의 | 말 없음 (화면만) | 30분에 한 번 가벼운 질문 | 8분마다 말 걸기 |
| 경고 | "쉬어갈까, 반응 게임으로 잠 깨워줄까?" 한 번 (15분 간격) | 같음 | 5분 간격 |
| 위험 | 경고 한 문장 + 휴게소 안내 (10분 간격) | 같음 | 5분 간격 |
| 휴식 | "10분만 쉬어가" 한 문장, 스트레칭은 화면 | 같음 | 스트레칭 음성 안내 |
| 운행 종료 | 화면 리포트만 | 짧은 인사 | 음성 리포트 |
| 환기 (내기순환 20분+ · 주의 이상) | 화면 안내만 | 한 문장 (30분 간격) | 같음 |
| 시간당 상한 (위험 경고 제외) | 2회 | 4회 | 6회 |

- 위험 경고는 어느 단계에서도 꺼지지 않습니다.
- 바꾸는 방법: 정차 화면의 [운전자 변경] 버튼 → 창 맨 위 "달토끼 말 수"(운전자별 설정), 또는 운전 중 "조용히 해"(한 단계 아래) / "말 좀 해줘"(한 단계 위).
- 끝말잇기·퀴즈·반응 게임은 운전자가 "달토끼야, 끝말잇기" / "반응 게임 하자"라고 하거나 화면의 게임 버튼을 누르면 언제든 시작합니다.

### 4. 화면 (D안 · 점수형 위젯, 주행용으로 단순화)

- **주행 중:** 달토끼 초상화 링(링 길이·색 = 졸음 위험도) + 큰 상태 글씨("좋아요/주의/경고/위험")와 위험도 숫자 → 상태 한 줄("차선 변경 중 · 달토끼는 잠깐 기다려요" / "깨어 있음 확인 +12 · 3연속 정답" / 잠김 / 환기 안내 / 연속 운전·다음 휴게소) → '주의' 이상이면 **판단 근거 알약**("핸들 무조작 후 급꺾음 2회(5분)", "대답이 평소의 2.1배") → "달토끼" 말 카드 → [말놀이 게임] [휴게소]. 머리글은 앱 이름 없이 지금 운전자 이름만
  - 각성 점수·콤보·배지는 운전 중 화면을 보게 만들지 않도록 정차 화면에서만 보여줍니다.
  - 스크롤 없이 화면 높이에 맞춰 게이지가 줄어듭니다(내비 옆 분할 화면, 휴대폰 가로·세로).
- **위험:** 빨간 테두리, 휴게소 카드(+500), [경로에 추가] [괜찮아요] — 대답 대신 버튼으로
- **정차 중:** 휴식 타이머·스트레칭, 각성 점수·배지, 말 수 설정, 운행 리포트(차량 주의 경고 횟수 포함)

### 5. 정확해야 하는 일은 규칙으로, 자연스러워야 하는 일은 AI로

- **끝말잇기 판정**(두음법칙·중복·시작 글자, "음… 기차" 같은 군말 처리)과 **퀴즈 채점**은 LLM이 아니라 코드로 합니다.
- 자유 대화의 짧은 반응은 규칙 기반 응답입니다. Pleos 참가자용 SDK 목록에 대화형 LLM SDK가 없기 때문입니다.
- Gleo 음성비서와는 공식 방식인 **Gleo Interface**로 연결했습니다(아래 6절).

### 6. 바쁜 순간에는 말 걸지 않기 · 판단 근거 보여주기

- 방향지시등(차선 변경), 시속 30km 이상에서 브레이크·급감속(초당 8km/h 이상), 큰 핸들 조작(90° 이상 또는 초당 30° 이상) 중에는 **새로 말을 걸지 않고**, 끝난 뒤 3초까지 기다립니다. 위험 경고만 최대 5초까지 미룬 뒤 말합니다. (졸음 판정은 계속하고, 말하는 시점만 늦춤. 졸음 급꺾음은 초당 12~25°라 바쁜 순간으로 보지 않음)
- 판단 근거를 최대 3개 보여줍니다: 차량 주의 경고 / 졸리다고 말함 / 핸들 무조작 후 급꺾음 N회(5분) / 무응답 N회 / 대답이 평소보다 N배 느림 / 차로 이탈 N회 / 핸들 미세 보정 평소의 N% / 연속 운전 시간 / 새벽·오후 졸음 시간대
- 데모 패널의 **차선 변경 5초 / 브레이크 3초** 버튼으로 시험합니다.

### 7. Gleo 음성비서 연동 (Gleo Interface)

`app/src/main/assets/schema.json`에 함수 3개(공식 상한)를 등록했습니다. Gleo가 부르면 `GleoActionReceiver`가 받아 처리하고 7초 안에 결과(`APP_ACTION_RESPONSE`)를 돌려줍니다. 달토끼가 직접 말하므로 응답 모드는 `silent`입니다.

| 함수 | 하는 일 |
|---|---|
| `START_WORD_GAME` | 달토끼와 끝말잇기 시작 (위험 단계면 휴식 안내) |
| `REPORT_DROWSINESS` | 졸림 신고 → 최소 '경고' 유지 + 휴게소 안내 |
| `ADD_REST_STOP` | 진행 방향 앞쪽 같은 차로의 가장 가까운 휴게소를 경유지로 추가 |

Gleo 없이 시험: 데모 패널의 **Gleo 음성비서 호출 시험** 버튼, 또는
`adb shell am broadcast -a START_WORD_GAME -p app.daltokki.drive`

### 데모 패널 시험 설정 (24차)
- [가벼운 연출]: 입자 절반·빛 번짐 없음 (느린 에뮬레이터)
- [실제 내비 연동 시험]: 시뮬레이션에서도 실제 Pleos 내비에 경유지 넣기 (기본 끔 — 켜면 내비 앱이 앞으로 나와 화면이 바뀜. 자동 시연 중에는 항상 끔)

### 위험도 내려감 표시 (23차)
- 행동 덕분에 졸음 위험도가 실제로 내려가면 숫자 옆에 "−7 · 빠른 대답 / 외기 전환 / 휴식" (관련 신호가 좋아졌을 때만, 점수와는 무관)

### 보상 연출 (22차) — 운전 중엔 귀로 쌓고 · 쉬면 눈으로 터진다
- 운전 중: 정답·안전 행동마다 달빛 조각 1개(점수판 옆 주머니), 콤보 칭찬 3·5·7연속(5연속 팡파르)
- 10분 휴식: 휴식 잭팟(도장 쾅 → 조각 빨려 듦 → 내역 한 줄씩 → 합계 금색 + 팡파르·입자 80개 → 레벨 업)
- 달빛 선물 상자(쉴 때마다 하나): 보너스 50~300점 또는 꾸미기 5종(첫 선물은 꼭 꾸미기, 바로 착용)
- 운행 결과: 별 3개(안전 운행·안전 행동 2번·3콤보) · 등급 S/A/B/C · 신기록 띠

### 안전 행동 점수 (21차)
- 졸음을 줄이는 행동도 점수: 외기 전환·온도 낮추기 승낙 +30(음성 안내로 대신 +10), 휴게소 경로 추가 +100, 권장 시간 전에 쉼(제때 쉬기) +200, "졸려" 먼저 말함 +50, 컨디션 체크 +20. 같은 행동은 30분에 한 번. 청록색 연출·바람 종소리. 배지 '상쾌한 운전'·'제때 쉬기'(17종)
- 운행 리포트 점수 내역(게임 · 안전 행동 · 휴식 · 도장)

### 점수 연출 (20차)
- 게임 중 점수판(자리마다 굴러가는 점수 · 날아와 합쳐지는 "+100" · 콤보 배지 "3연속 ×2" · 번개 +30), 정답이면 링에 달빛 한 번, 3연속부터 "3 콤보!"·두 겹 빛·콤보 음, 5연속부터 달빛 모드(금빛 링·"5연속! 달빛 모드야!"), 콤보 끊김 "최고 N연속", 게임 끝 요약
- 정차 중 휴식 완료(도장 "쾅")·커피냅·달 레벨 상승(달이 차오름)은 별가루 축하, 새 배지는 카드 뒤집기
- 실제 주행 화면 제한이면 움직이는 연출을 끄고 숫자·소리만

### 운행 리포트 · 안전 운행 연속 기록 (19차)
- 운행이 끝나면 **운행 리포트** 창: 운전·휴식·가장 피곤했던 단계, **차량 주의 경고보다 먼저 알아챈 시간**, 졸음 위험도 흐름 그래프, 반응 게임·커피냅 전후 반응, 차선 변경·통화 중 기다린 순간, 이번 주 요약. 정차 화면 '지난 운행 ›'으로 다시 열기
- **안전 운행 N번 연속**(졸음 신호 없이 끝났거나 졸리면 쉰 운행)·주간 리포트(지난주와 비교) — 운전자별, 기기 안에만
- 정차 화면 '휴게소 도장 ›' → 도장첩(노선별 진행·최근 도장), 운전자 창 → 운전 습관 평소 vs 지난 운행
